# S&N Home and Analytics

Two native windows carry the rest of the plugin's admin: **S&N Home** (the dashboard: Site, Content, Connections, Measurement, AI, Security, Integrity) and **S&N Analytics** (the views over the analytics table and Search Console).

A door from an Attention item ("Open Trust checks in S&N Dashboard") opens the native window on the named tab when that window is enabled in OS Settings, Signal & Noise. With the native window turned off, the same door opens the classic admin page in a window.

Integrity verdicts live in S&N Home, Integrity, Trust checks. The Provenance tab's Commits table lists pending proofs only; when it is empty and the last sweep reported failures, it says so and points at Trust checks.
