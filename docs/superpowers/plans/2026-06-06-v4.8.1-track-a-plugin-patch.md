## Task 9 — Conditional-GET (Last-Modified + 304) for RSS feeds  *(new `tests/feed-conditional-get.php`)*
**File:** `inc/seo.php` — a sibling `add_action('template_redirect', …)` after the existing singular Last-Modified handler (priority **10**, so it runs *after* `sn_rss_tracker_capture` at priority 1 — never pre-empt feed tracking).
**Change:** pure decision helper + thin wrapper:
```php
function sn_seo_feed_conditional_response( $modified_gmt, $if_modified_since, $if_none_match, $etag ) {
	if ( ! $modified_gmt ) { return null; }
	if ( $if_none_match && trim( $if_none_match ) === $etag ) { return array( 'status' => 304 ); }
	if ( $if_modified_since && strtotime( $if_modified_since ) >= $modified_gmt ) { return array( 'status' => 304 ); }
	$http = gmdate( 'D, d M Y H:i:s', $modified_gmt ) . ' GMT';
	return array( 'status' => 200, 'headers' => array( 'Last-Modified' => $http, 'ETag' => $etag ) );
}
```
Wrapper: `if (function_exists('the_seo_framework')) return; if (!is_feed()) return;` → `$ts = (int) get_feed_build_date('U');` (category-accurate for `/notes/feed/`) → `$etag = '"' . md5( gmdate('D, d M Y H:i:s',$ts).' GMT' ) . '"';` → call helper → emit headers / `status_header(304); exit;`. Mirror the SERVER_PROTOCOL allowlist from the singular handler.
**Test:** `tests/feed-conditional-get.php` on the helper — IMS ≥ modified → 304; IMS < modified → 200 + correct Last-Modified; matching INM ETag → 304; no conditionals → 200 + both headers; `$modified_gmt`=0 → null. Plus assert the action is registered at priority >1.
**Commit:** `feat(perf): conditional-GET (Last-Modified + 304) for RSS feeds`
