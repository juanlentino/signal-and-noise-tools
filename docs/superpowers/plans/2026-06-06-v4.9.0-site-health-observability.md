## Task 1 — Cloudflare security-header drift check *(SN Health registry)*
**File:** `inc/health-checks.php`. Add a `cf_security_headers` check to the `checks` array in `sn_health_run_scan()` + a `sn_health_check_cf_security_headers()` fn near `sn_health_pack_check()`. Add an `SN_HEALTH_CF_HEADERS_TTL` constant (6h) by the other TTLs.
**Change:** read a 6h transient `sn_health_cf_headers_probe`; on miss fire **one** `wp_remote_head( home_url('/'), ['timeout'=>5,'redirection'=>2,'sslverify'=>true,'headers'=>['User-Agent'=>'SignalNoiseTools/'.SNT_VERSION.' header-drift-check']] )`. On `WP_Error`, return a pack with a probe-failed note **without caching** (self-heals). On success, normalize `wp_remote_retrieve_headers($resp)` to **lower-case keys** (it returns a `CaseInsensitiveDictionary` on live WP — cast `(array)` / handle both), assert presence of the 5 delegated headers (`content-security-policy`, `strict-transport-security`, `x-content-type-options`, `x-frame-options`, `referrer-policy`). Each missing → a finding row matching the existing shape (`subject_type` `security_header`, `subject_label` = header name, `subject_url` = home_url, note "Expected at the Cloudflare edge but absent — verify the CF Transform Rule / Managed Headers"). Cache the missing-array 6h. Gate the whole check behind `apply_filters('sn_health_cf_header_check_enabled', true)`. Do NOT add to `$suggest_supported_checks` (no AI-fix column).
**Test:** new `tests/health-checks-cf-headers.php` — stub `get_transient`/`set_transient` (via `$GLOBALS`), `wp_remote_head` (injectable fixture + call counter), `wp_remote_retrieve_headers` (lower-cased assoc), `home_url`, `is_wp_error`/`WP_Error`. Assert: all-5-present → 0 findings; drop `x-frame-options` → 1 finding w/ that label; drop CSP+HSTS → 2; **cache hit** → `wp_remote_head` NOT called; `WP_Error` → 0 findings AND transient NOT written. (The stub must return the same lower-cased shape the impl normalizes to — the falsification lesson.)
**Commit:** `feat(health): Cloudflare security-header drift check`
