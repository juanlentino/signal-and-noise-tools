# Plugin v5.0.0 — Modernization Major Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use `- [ ]`. TDD throughout — every behavioral change gets a failing test first; mechanical removals get a "the removed thing is gone / suite still green" gate.

**Goal:** Ship plugin v5.0.0 — a pure modernization major: raise the WP floor to 7.0, remove the 4 gen-1 `@deprecated since 2.5.0` REST routes, promote the 6 gen-2 `@deprecated since 4.6.0` surfaces to runtime warnings (removal targets v6.0.0), delete the orphan option + the WP<7.0 admin-notice compat file.

**Architecture:** All four gen-1 routes have live Ability replacements; 3 of 4 JS clients already use the Ability path (the 4 desktop-mode widgets need flipping before `/cmd` can go). Shared `*_impl()` pure functions + AI constants are load-bearing (Abilities + publish-time prepopulate engine) and MUST be preserved — only the route registration, permission callback, and deprecated REST handler are deleted per route.

**Tech stack:** WordPress plugin (PHP 8.0+, WP 7.0+ after this release), WP Abilities API, standalone `tests/*.php` fixtures (summary line `N passed, M failed`), PHPCS security ruleset (falsify before trusting clean).

**Source of truth for verbatim blocks:** the `v5-recon` workflow output (run `wf_9f06b9b4-d59`) captured every exact code block + line range cited below.
