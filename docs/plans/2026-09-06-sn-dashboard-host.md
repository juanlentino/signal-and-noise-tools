1. `inc/openstation-host.php`:
   - `snt_os_host_capture( callable $paint, array $get = array(), array $post = array() )`: sets `$_GET`, `$_POST`, `$_REQUEST` for the duration (merging `page`), runs the callable under `ob_start()`, returns the HTML, restores all three superglobals in a `finally`. Pin: a callable that reads `$_GET['tab']` sees it; after the call the superglobals are byte-identical to before; a throwing callable still restores.
   - `snt_os_host_rewrite( $html, array $own = array( 'sn-theme-options' ) )` over `WP_HTML_Tag_Processor` exactly per the spec's table: post forms → `os-action="post"` and `action` removed; get forms → `os-action="go"`; anchors to our pages → `os-action="go"` + `os-arg-tab/sub/anchor` (+ every `sn_*` query param as `os-arg-<name>`), `href` removed; anchors to other admin URLs (`admin_url()` prefix or a relative `wp-admin/`) → `os-action="door"` + `os-arg-url`, `href` removed; external `http(s)` anchors without `target` → `target="_blank" rel="noopener noreferrer"`; `<script>` → `data-snt-exec="1"`; `#fragment`-only anchors, `mailto:`, `javascript:` and anchors already carrying `os-action` untouched. Pin every case on one fixture and pin that a link to `/wp-admin/admin.php?page=sn-theme-options&tab=monitoring&sub=health#sn-sec-x` becomes `go` with tab/sub/anchor and no href. Mutation: drop one branch, the matching pin goes red.
   - `snt_os_host_replay( array $values, $page_slug )`: `manage_options` else `array( 'ok' => false, 'flash' => '' )`; `wp_verify_nonce( values['_wpnonce'], 'sn_theme_options_nonce' )` else `nonce`; `sn_action` must exist in `sn_admin_post_handlers()` else `unknown`; `$_POST = wp_slash( $values )`, `$_REQUEST = array_merge( $_GET, $_POST, [ 'page' => $page_slug ] )`, call the handler with `$_POST`, capture the returned flash code, restore the superglobals in a `finally`; return `[ ok, flash, target ]` where target = `sn_admin_post_redirect_target( … )` resolved the way inc/admin-post-handler.php resolves it (read it; reuse the pure pieces, never `header()`/`exit`). Pins: capability, nonce, unknown action (handler NOT called), a handler that reads `$_REQUEST['page']`, slashing (a value with a quote reaches the handler slashed, exactly as admin-post would), superglobals restored.
   - `snt_os_host_notice( $flash )`: `sn_admin_flash_to_notice()` → `[ severity, html ]` or null; `snt_os_host_toast_text( $notice )` = `wp_strip_all_tags()` of the html.
