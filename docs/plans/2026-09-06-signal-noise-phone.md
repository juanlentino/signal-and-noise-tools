# The phone — contract plan (phase four, #1071)

> **For agentic workers:** CONTRACTS, not verbatim code. Read first: the spec `docs/proposals/2026-09-06-signal-noise-app-phone.md`, the code map `<session>/map4/` (mobile-runtime.md, attention-signals.md, app-on-phone.md, stale-build.md; every reader's signature, shape, cost and stamp is there with file:line), the earlier plans' headers (docs/plans/2026-09-06-signal-noise-control-surface.md, 2026-09-06-signal-noise-more-sections.md) for the runtime facts and the house rules, and the app as it stands. Three builders on disjoint files; docs after.

**House rules:** as before (never commit; own files only; test conventions; stub-parity; the orphan-class pin; one `ctx.ui(`; no `/wp-abilities/` literal; the readers READ and never compute; a reader that fails is a warning row, never a zero; every string says what was measured and when).

## Task A — Attention (server): `apps/signal-noise/parts/attention.php`, `tests/openstation-app-attention.php`; plus `parts/discography.php` (a `count`), `signal-noise.os.php` (require attention.php; the `jump` action; `version` in config), `parts/payload.php` (`version`), `tests/openstation-app.php` (the order and count pins the new section moves; the `version` payload pin; the `jump` action pin).

- **Readers**, each wrapped in try/catch and function_exists, each returning `array( 'rows' => [...], 'stamp' => 'Y-m-d H:i:s' | '', 'unreadable' => bool )`: `attention_integrity()` from `sn_prov_integrity_state()` findings (one row per note failure, title the note, subtitle the failure sentence via `sn_prov_integrity_failure_sentence()`, stamp the sweep's `checked_at`); `attention_anchors()` from `sn_prov_admin_status()` rows whose status is unanchored or pending (title the post, subtitle "vN unanchored since <committed_at>" / "vN pending since …", tone warning for unanchored, neutral for pending); `attention_edge()` from the probe log rows with result stale (newest per post; subtitle "Edge served a stale render, probed <ago>", escalated noted); `attention_citations()` (never_checked > 0 → one row "N citations never checked"; due → one row "N citations due for a check"; the store failing → the unreadable row); `attention_schedule()` from `sn_admin_schedule_ordered_rows()` filtered to a transition within 24 h (fragments and posts; subtitle "opens/closes/publishes at <time>"); `attention_pending()` from `wp_count_posts( 'post' )->pending` (+ pages); `attention_health()` from `sn_health_last_scan()` failing checks (title the check's label, subtitle its message, stamp `scanned_at`); `attention_watches()` from `snt_watches_ripe()`; `attention_readers()` when `snt_mr_snapshot_is_stale() === true`.
- **Composition** `attention_rows()`: runs the readers, orders rows danger → warning → neutral then by stamp desc, caps at `SN_OS_APP_ITEM_CAP`, caches `array( 'rows', 'read_at' )` in transient `snt_os_attention` for 60 s; `attention_items()` maps rows to entry items (`id` `a-<kind>-<key>`, `status` = kind, `statusLabel`, `dateLabel` = the stamp as "as of …", badge `{ text: kind label, tone, title: the stamp }`, `columns { fact, stamp }`, `detail { hero '', facts [[Subject],[What],[When],[Source]], blocks [], actions [door, jump?] }`); `attention_count()` = count of cached rows. Statuses = the kinds. Descriptor: `id attention, label Attention, icon dashicons-flag, kind entry, position 5, capability manage_options, columns [fact, stamp]`. Empty: the client's empty state gets the heading through a new descriptor key `empty_heading` ("Nothing needs you") projected by payload.php and read by the client's empty state (Task B) — with the newest stamp in `empty_note`.
- **`jump` action** in signal-noise.os.php: `args { section, item }`; sets `section` (when the registry knows it) and `item` (string), resets query/verdict/selected, sets status to '' (All) so the item is visible whatever its status; the client's existing render opens the dossier for a set `item`. Attention rows that name a post carry `{ label: 'Open the note', dispatch: 'jump', args: { section: 'notes'|'pages', item } }`.
- **Version**: `->config( array( 'dossierUrl' => …, 'version' => SNT_VERSION ) )` and `'version' => SNT_VERSION` in payload().
- **Discography** gains `'count' => function () { return count( entries ) }` without building items.
- **Tests** (new suite over stubbed readers): each reader's rows and stamps; the unreadable row when a reader throws and when it returns null; the order; the cap; the cache (second call within 60 s reads the transient, a call after it recomputes — stub time via a `$GLOBALS['__now']` read by `attention_now()`); the empty queue's heading and stamp; `jump` sets both keys and clears the rest; the descriptor keys; `version` in config and payload equal to SNT_VERSION; Discography's count without items. Move the order/count pins in tests/openstation-app.php (attention first).

## Task B — the client (`apps/signal-noise/signal-noise-client.js`, `signal-noise.css`, `tests/openstation-app-client.php`)

- **Stacked list on the phone**: `?stacked=${ phone }` on `<os-table>`, and `sticky-columns` only when not phone.

- **Back**: on the phone item page, a `<os-button variant="ghost" class="snt-back">‹ Back</os-button>` in the detail header, before the title, calling `ctx.local( 'close' )`; every section.
- **Canvas long press**: wire the long-press handlers on `.snt-canvas` (empty-canvas presses only: a press that started on a cell is the cell's) to open the canvas menu.
- **Callouts**: duplicate the two suppression rules under `@media (pointer: coarse)`; remove the `is-phone` class from the two emits (or define it; removing is the honest fix).
- **Empty state**: the empty-state heading reads `data.section.emptyHeading` when present, else the current text; a `data.section.emptyNote` paints as a muted line under it.

Never automatic.
- **Pins**: `?stacked=`, the mode event name, `snt-back`, `snt-stale`, `location.reload()` appears exactly once and inside a click handler, `emptyHeading`, the coarse-pointer media rule in the CSS, `is-phone` absent, the orphan-class pin still green, one `ctx.ui(`.
