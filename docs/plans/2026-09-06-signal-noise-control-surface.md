# The control surface — contract plan (phase two, #1065)

> **For agentic workers:** this plan carries CONTRACTS, not verbatim code. Each task names its files, the exact keys, names, strings and pins it must produce, and the house rules. Build it; do not widen it. Two builders run in parallel on disjoint files.

**Goal:** selection, a context menu, four gated server actions and drag-out for the Notes section of the Signal & Noise app, in the WP Explorer's idiom, with the app's existing behaviour untouched.

**Read first:** the spec `docs/proposals/2026-09-06-signal-noise-app-control-surface.md`; the code map under `<session>/map2/` (framework-controls.md, explorer-idiom.md, operations.md, app-today.md); OpenStation 1.1.6 at `<scratchpad>/openstation` (apps/my-wordpress/parts/{wire,rows,list-views,helpers,long-press}.ts, parts/actions.php, src/app-runtime/{selection,session,index}.ts, src/ui/components/os-context-menu/os-context-menu.ts, includes/framework/app/class-effects.php); phase one's plan header (13 amendments, `docs/plans/2026-09-05-signal-noise-deeper-note.md`).

**Decided runtime facts (verified 2026-09-06):**
1. `ctx.dispatch( action, args, { confirm: { title, message, label, danger } } )` shows `<os-confirm-dialog>` first and resolves false without dispatching when declined or when `host.confirm` is missing (session.ts:320-345).
2. An action's effects: `$os->toast( $message )` (no tone, no duration), `$os->announce( $type, $action, $ids )`, `$os->open_url()`, `$os->menu()` and seven more (class-effects.php:43-213). No confirm, focus or undo effect exists.
3. `State::reset( $key )` restores the DECLARED default (class-state.php:180-185); an array default accepts arrays.
4. `applySelection( current, id, { shift, toggle }, order )` implements the Finder rules with the LAST selected id as the shift anchor (selection.ts:17-37). `createMarquee( { canvas, className, onChange } )` refuses presses on a row, clears on a plain start, keeps on a modified one, reports intersecting `data-item-id`s (selection.ts:66-103); the Explorer passes every change as a replace.
5. Drag: `window.wp.os.dragManager.start( { payload: { type: 'shortcut', source: rowEl, data: { kind, ref, title, icon, entityId, restPath, items? } }, origin: pointerEvent } )` (wire.ts:63-120); refuse `e.button !== 0`, any modifier, and the phone (`wp.os.mode.isMobile()`).
6. The menu is app-authored: `ui.menu = { x, y, item }` in the ui bag; `<os-context-menu open class style="position:fixed;left:Xpx;top:Ypx">` with `<os-context-menu-option id icon ?disabled ?danger heading>` children, `@os-context-menu-pick` whose `detail.id` is the option id; a full-window backdrop closes it (list-views.ts:304-479). Long press: 500 ms, 10 px slop, `pointerType` touch or pen, primary pointer (long-press.ts).
7. The Explorer's per-item rights ride the ITEM (`canEdit`, `canDelete`; lists.php:228-229); a menu action scopes to the selection only when the clicked item is in it and the selection has more than one member (list-views.ts:317-324).
8. `sn_cf_post_purge_urls( $post_id, $post )` → URLs; `sn_cf_purge_urls( array $urls )` → false when unconfigured (cloudflare-purge.php:99-112, :431); the save hook schedules `SN_CF_PROBE_HOOK` with `array( $post_id )` at `time() + SN_CF_PROBE_DELAY`, unscheduling a pending one first (:441-447). `sn_prov_reconcile_post( $post_id )` re-dispatches `unanchored` commits and returns false for a protected post (provenance-webhook.php:537+). `sn_prov_get_chain( $id )` rows carry `status` (genesis|unanchored|pending|confirmed).
9. The client's ONE `ctx.ui()` bag is `{ folderSel, dossiers, errors, inflight, days }`; the count is pinned at 1. The dossier fetch is gated to Notes in exactly two places (pinned count 2).
10. The test stubs (tests/openstation-app.php:40-80): `State` with `reset` from declared defaults, `Os` with `open_url()` and `can()` recording `$GLOBALS['__can_calls']`; `current_user_can` records `$GLOBALS['__cap_calls']`.

**House rules:** never commit/push/checkout/stash/reset; leave files in the tree. Every test: CLI guard, `define( 'ABSPATH', '/' )`, stubs before the require, `ok()`, the final `Result: N passed, M failed.` line and exit code. WP-shaped stubs must be real WP functions (stub-parity); `sn_`/`snt_` stubs are exempt. Tabs, Yoda, phpcs WordPress-Extra. No CSS class in PHP that the stylesheet does not define (the orphan ratchet; the client is JS, so classes it emits must exist in signal-noise.css). ASCII-safe strings in PHP (`__()` everywhere). No `/wp-abilities/` literal in JS. Exactly one `ctx.ui(` in the client. Never write the probe log from an action. Do not touch the Discography section, the dossier builders, or phase one's behaviour.

**Items (notes.php).** Each item gains: `'canEdit' => current_user_can( 'edit_post', $id )`, `'canDelete' => current_user_can( 'delete_post', $id )`, `'canPublish' => in_array( $post->post_status, array( 'draft', 'pending', 'future' ), true ) && current_user_can( 'publish_posts' ) && current_user_can( 'edit_post', $id )`, `'unanchored' => (bool)` any chain commit with `status === 'unanchored'` (read from the chain phase one already loads for the badge; no second read), `'link' => get_permalink( $post )`. The existing `detail.actions` row is unchanged.

**Payload.** Add `'can' => array( 'purge' => current_user_can( 'manage_options' ) && function_exists( 'sn_cf_is_configured' ) && sn_cf_is_configured(), 'anchor' => current_user_can( 'manage_options' ) && function_exists( 'sn_prov_reconcile_post' ) )` at the root, after `verdict`.

**Actions (parts/actions.php, namespace `SignalNoise\App`, functions `trash_action`, `publish_action`, `purge_action`, `anchor_action`, helpers `targets`, `note_allowed`).**
- `targets( State $state, array $args ): int[]` — the clicked `item` (int) plus, when `$args['selection']` is truthy AND the clicked id is in `$state->get( 'selected' )` AND that selection has more than one member, every selected id; ids `<= 0` dropped; unique; ints. The CLIENT decides `selection` by the Explorer's rule and the SERVER re-checks it against state, so a forged `selection: true` with a one-member selection still acts on one item.
- `note_allowed( Os $os, int $id, string $what ): bool` — `get_post( $id )` must be a `post` post type; then `edit` → `$os->can( 'edit_post', $id )`, `delete` → `$os->can( 'delete_post', $id )`, `publish` → `$os->can( 'publish_posts' ) && $os->can( 'edit_post', $id )`, `manage` → `$os->can( 'manage_options' )`.
- `trash_action`: for each target allowed `delete`, `wp_trash_post( $id )`; collect done. Reset `selected`; if the open `item` was trashed, `reset( 'item' )` and `reset( 'verdict' )`. Toast: none done → `__( 'Nothing could be trashed.' )`; one → `__( 'Moved to the Trash.' )`; many → `sprintf( _n( 'Moved %s item to the Trash.', 'Moved %s items to the Trash.', $n ), number_format_i18n( $n ) )`. `$os->announce( 'post', 'trashed', $done )` when any. (The Explorer's strings, verbatim.)
- `publish_action`: single target only (`$args['item']`); allowed `publish` and status in draft|pending|future; `wp_update_post( array( 'ID' => $id, 'post_status' => 'publish' ) )` (this fires the plugin's own publish hooks: signing, purge, schedule sync); toast `__( 'Published.' )` or `__( 'Nothing could be published.' )`; announce `'post', 'updated', array( $id )` on success; reset `verdict` (the chain changes).
- `purge_action`: targets allowed `manage`; if `! function_exists( 'sn_cf_is_configured' ) || ! sn_cf_is_configured()` → toast `__( 'Cloudflare is not configured.' )` and return. For each target: `$urls = sn_cf_post_purge_urls( $id, get_post( $id ) )`, accumulate; one `sn_cf_purge_urls( $all )`; then for each target reschedule the probe exactly as the save hook does (`wp_next_scheduled` / `wp_unschedule_event` / `wp_schedule_single_event( time() + SN_CF_PROBE_DELAY, SN_CF_PROBE_HOOK, array( $id ) )`), guarded on `defined( 'SN_CF_PROBE_HOOK' )`. Toast `sprintf( _n( 'Purged %s URL at the edge; the probe checks it in two minutes.', 'Purged %s URLs at the edge; the probe checks them in two minutes.', $count ), number_format_i18n( $count ) )` or `__( 'Nothing to purge.' )`. NEVER write `SN_CF_PROBE_LOG_OPT`.
- `anchor_action`: single target allowed `manage`; if the chain has no `unanchored` commit → toast `__( 'Nothing to dispatch: every version is anchored or pending.' )`; else `sn_prov_reconcile_post( $id )` and toast `__( 'Anchor dispatch retried; the ledger answers when it lands.' )` or `__( 'The dispatch could not be retried.' )` on false; reset `verdict`.
- Register in `.os.php`: `->action( 'trash', __NAMESPACE__ . '\trash_action' )` … for the four, AFTER `verify`; `require_once __DIR__ . '/parts/actions.php'` beside the existing part requires. Update the file's header docblock: seven actions.

## Task B — client: selection, menu, actions, drag, footer, CSS, tests

**Files:** modify `apps/signal-noise/signal-noise-client.js`, `apps/signal-noise/signal-noise.css`; create `tests/openstation-app-client.php`. Do NOT edit any PHP under apps/ or inc/, and do NOT edit tests/openstation-app.php (Task A owns them).

**API bag.** Destructure additionally `applySelection, createMarquee, copyText` from `api` (all exist in CLIENT_API).

**ui bag.** Extend the ONE `ctx.ui()` factory to `{ folderSel: null, dossiers: new Map(), errors: new Map(), inflight: new Set(), days: 30, menu: null }`. Still exactly one `ctx.ui(` in the file.

**Selection.** A local reducer `select: ( state, args )` where `args = { id, shift, toggle, order }`: `state.selected = applySelection( state.selected || [], String( args.id ), { shift: !! args.shift, toggle: !! args.toggle }, ( args.order || [] ).map( String ) )` — ids are STRINGS in this app (state.item is a string). A second reducer `'select-set': ( state, args ) => { state.selected = ( args.ids || [] ).map( String ); }`. The existing tile `@click=${ open }` becomes: compute `{ shift: e.shiftKey, toggle: e.metaKey || e.ctrlKey }`; dispatch `select` with the visible order; then, for a plain click only, `open` as today (select and preview are one gesture; a modified click only changes the selection). The list rows do the same on `os-table-row-click` when the event carries the modifier keys (read `e.detail.originalEvent` if the kit provides it; otherwise treat a row click as plain). Tiles/cells with an id in `state.selected` carry class `is-selected` and `aria-selected="true"`.

**Marquee (desk only).** In `mounted`, when `! isPhone()` and `createMarquee` exists: `createMarquee( { canvas: ctx.root.querySelector( '.snt-canvas' ) …` — the canvas element the tiles live in (add `data-snt-canvas` to it if it has no stable hook), `className: 'snt-marquee'`, `onChange: ( ids ) => ctx.local( 'select-set', { ids } ) } )`; re-attach after repaint if the runtime replaces the node (mirror wire.ts:126-135 and its teardown). Add `data-item-id` to every tile cell and row so the marquee can report them.

**Footer.** Below the body, on both desk and phone: `<footer class="snt-status-bar"><span>${ sprintf( __( '%1$d of %2$d items' ), shown.length, data.items.length ) }${ selected.length ? sprintf( __( ' — %d selected' ), selected.length ) : '' }</span></footer>` (only when a section is open and no item page is open on the phone).

**Menu.** `openMenu( ctx, x, y, item )` sets `ui.menu = { x, y, item }` and repaints; `closeMenu`. Triggers: `@contextmenu` on tiles and rows (preventDefault, stopPropagation), a `<os-button variant="ghost" class="snt-more" aria-label=${ __( 'More actions' ) }>⋯</os-button>` in each row's cluster and in the dossier header (opens at the button's rect bottom-left), and a plain-JS long press (500 ms, 10 px slop, touch/pen, primary) on tiles/rows. `renderMenu( ctx )` paints `<div class="snt-menu-backdrop" @click=close @contextmenu=close>` + `<os-context-menu open class="snt-menu" style="position:fixed;left:${x}px;top:${y}px" @os-context-menu-pick=${ pick }>` with options in this FIXED order and ids: `edit` "Open in editor" (icon dashicons-edit; disabled unless `item.canEdit`), `view` "View on site" (disabled unless `item.link`), `copy-link` "Copy link", `copy-id` "Copy ID", `verify` "Re-check now" (disabled unless `item.canEdit`; only when the item has a chain, i.e. the detail carries a Verify/Re-check action — read `item.detail.actions` labels), `purge` "Purge edge cache" (disabled unless `data.can.purge`), `anchor` "Retry anchor dispatch" (shown only when `item.unanchored`; disabled unless `data.can.anchor`), `publish` "Publish" (shown only when `item.canPublish`), `trash` "Move to the Trash" (danger; disabled unless `item.canDelete`). Escape closes the menu BEFORE the existing Escape handler closes the dossier (check `ui.menu` first).

**Action runner.** `runAction( ctx, id, item )`: `const many = ctx.state.selected.includes( item.id ) && ctx.state.selected.length > 1; const n = many ? ctx.state.selected.length : 1; const args = { item: item.id, selection: many };` then: `edit` → `ctx.dispatch( 'edit', { item: item.id, title: item.title } )`; `view` → `window.open( item.link, '_blank', 'noopener,noreferrer' )`; `copy-link` → `copyText( item.link )` and `ctx.host.toast( { message: __( 'Link copied.' ) } )`; `copy-id` → `copyText( item.id )` + toast `__( 'ID copied.' )`; `verify` → `forgetDossier( ctx, item.id ); ctx.dispatch( 'verify', { item: item.id } )`; `purge` → `ctx.dispatch( 'purge', args )` then `forgetDossier` for each target; `anchor` → `forgetDossier( ctx, item.id ); ctx.dispatch( 'anchor', { item: item.id } )`; `publish` → `ctx.dispatch( 'publish', { item: item.id }, { confirm: { title: __( 'Publish this note?' ), message: __( 'It will be signed now and, once the editing pass goes quiet, anchored in Bitcoin. A published version is permanent.' ), label: __( 'Publish' ) } } ).then( ok => ok && forgetDossier( ctx, item.id ) )`; `trash` → `ctx.dispatch( 'trash', args, { confirm: { title: '', message: many ? sprintf( __( 'Move %d items to the Trash?' ), n ) : __( 'Move this to the Trash?' ), label: __( 'Trash' ), danger: true } } )`. Close the menu first in every case.

**Drag lift (desk only).** In `mounted`: a `pointerdown` listener on `ctx.root` that refuses `e.button !== 0`, shift/ctrl/meta, and the phone; finds `[data-snt-drag][data-item-id]` (tiles and rows carry `data-snt-drag="post"` ONLY in the Notes section); resolves the item from `ctx.data.items`; builds `selectedItems` by the Explorer's rule; calls `window.wp.os.dragManager.start( { payload: { type: 'shortcut', source: rowEl, data: { kind: 'post', ref: item.id, title: item.title, icon: item.thumb || '', entityId: 'signal-noise:notes', restPath: ( ctx.data.section && ctx.data.section.restPath ) || '', ...( selectedItems.length > 1 ? { items: […] } : {} ) } }, origin: e } )` when `restPath` is non-empty; guard every `wp.os` access. Teardown removes the listener.

**CSS.** Add: `.snt-status-bar` (11px, muted, top border, padding 4px 10px), `.snt-cell.is-selected os-tile` / `.snt-row.is-selected` (the kit's selection tokens: `--os-tile-selected-bg` if defined, else a translucent accent), `.snt-marquee` (1px `var(--os-tile-focus-ring, #7c3aed)` border over `var(--os-selection-marquee-bg, rgba(124,58,237,.12))`), `.snt-menu-backdrop` (position:fixed; inset:0; z-index below the menu), `.snt-menu` (z-index above), `.snt-more` (ghost, 24px, visible on row hover/focus and always in the dossier header), phone rules under `html[data-os-mode="mobile"]` (no marquee, `.snt-more` always visible).

**Tests (`tests/openstation-app-client.php`, new).** Source-text pins over the client and the CSS: exactly `1 === substr_count( $js, 'ctx.ui(' )`; presence of `applySelection(`, `createMarquee(`, `copyText(`, `'select-set'`, `dragManager.start(`, `type: 'shortcut'`, `restPath`, `'signal-noise:notes'`, `os-context-menu`, `os-context-menu-pick`, `confirm:`, `danger: true`, `'Move this to the Trash?'`, `'Move %d items to the Trash?'`, `'Publish this note?'`, `snt-status-bar`, `'More actions'`, `data-snt-drag`, `e.metaKey || e.ctrlKey`, `isMobile` or `isPhone()` guarding the drag; the menu ids in ORDER (`indexOf` ascending for `'edit'`, `'view'`, `'copy-link'`, `'copy-id'`, `'verify'`, `'purge'`, `'anchor'`, `'publish'`, `'trash'` as option ids); no `/wp-abilities/`; every `snt-` class the client emits exists in the CSS (extract with a regex over `class="…"` and `class="snt-…"` template literals; assert each appears in signal-noise.css); the two Notes gates still count 2. `node --check` passes.
