# Changelog

All notable changes to Signal & Noise Tools are documented here.

This file holds two things only: **`## [Unreleased]`**, the working log that
accumulates across pull requests, and the **current release**. Everything older
lives in [docs/changelog/](docs/changelog/).

adds a bullet below. A release is a separate, deliberate act:
`tools/cut-release.sh`.

## [Unreleased]

### Fixed
- **Stale crawl compared the crawl to `post_modified`, which a tag edit bumps.** The first live reading of the rebuilt Posts view flagged 17 stale crawls; the edit dates clustered on 2026-09-09 and 2026-09-12, the two bulk saves (tag vocabulary, surfaces) that never changed a word. `sn_analytics_posts_row()` now carries `body_changed_ts`: the newest signed commit's `committed_at` (`sn_prov_last_commit_gmt_from_chain()`), falling back to `post_modified` only for an unsigned post; `sn_analytics_posts_flags()` reads that. The cell's title says "Body changed", the queue's implied fix says "last body change". Guards: a signed note whose body has not changed since the crawl is not stale however many bulk saves bumped it; a new commit after the crawl (even pending) is; no `committed_at` falls back; mutation (flag back on `post_modified`) red.

## [14.6.0] - 2026-09-14 — the Posts view reads the dense per-note signals; pageviews raw

### Changed
- **The Posts view is rebuilt around dense per-note signals; pageviews demoted to a raw number.** The view classified every note as sustained / cooling / spike from human pageviews, the thinnest signal the site collects (measured 2026-09-13: the highest lifetime count across 41 notes was 14, and notes were classified on samples of 6 and 7), while Search Console, URL Inspection coverage, the link graph, the provenance chain and the ML kernel were all stored per note and surfaced nowhere on it. New `inc/analytics-posts-signals.php` assembles one row per published note from the readers the note dossier already uses (`snt_gsc_metrics_for_path`, `snt_gsc_coverage_for_path`, `snt_ml_inbound_by_path`, `sn_note_dossier_anchored_commit`, `snt_ml_related_for_post`, `sn_analytics_path_lifetime`), so the tab and the dossier read the same row the same way. Every field is `{ value, why }`: a missing signal is null with its reason (not shown by Google in this window, not inspected in the last run, never crawled, unsigned, not in the kernel yet), never a zero. **Three flags, derived once** in `sn_analytics_posts_flags()`, each a true binary: `not_indexed` (coverage `indexed === false`), `stale_crawl` (last crawl before the last edit), `orphaned` (inbound links at or below 1); a gap never raises a flag. New `inc/analytics-posts-signals-admin.php` renders a header strip (machine reads once, site-wide, labelled as such; the Search Console window; the coverage run), counts that mean something (indexed, with impressions in window, zero inbound, stale crawls, total), a **queue of flagged notes only** sorted by severity with the fix each flag implies (Discovered and Crawled not-indexed get different sentences), and the full table behind "Show all notes", collapsed by default, thirteen columns (Note, Age, Words, Index, Last crawl, Impr, Clicks, Pos, Inbound, Anchor, Related, Views, Flags), every one sortable client-side with gaps sorting last both ways, titles never truncated. No em dashes in the tab's copy; flag labels are states, never verbs. Removed: the hero, the trajectory, the leaderboard, Launch velocity, Evergreen vs spike, Lifecycle at scale and the Refresh queue (`inc/analytics-posts-admin.php`, `inc/analytics-posts-lifecycle-admin.php`, `sn_annotation_lifecycle()`, their tests). The shape classifier survives only for the insights forecast and the recommendation card, now floored: `sn_analytics_lifecycle_classify()` claims no shape below `SN_POSTS_SHAPE_MIN_VIEWS` (15). The native window paints the same classic body; the partial-host painter fallback paints the counts and the queue. The theme and the analytics Worker are untouched (neither ever classified). Shape stability: no tracked subject carries this payload; no remote twin does. Guards: `tests/analytics-posts-signals.php` (43: every field real and absent, the stale-crawl boundary, both not-indexed states, the orphan threshold, gaps never flagging, kernel not-built vs not-indexed vs zero neighbours, counts, the strip), `tests/analytics-posts-signals-admin.php` (31: no em dash, no shape or verb vocabulary, machine reads exactly once, queue membership and order, thirteen sortable columns, full titles, gap cells with empty sort keys, real zeros as zeros, collapsed table); mutations red by name: stale boundary, null as not-indexed, gap as orphan, not-shown as 0, not-in-kernel as 0, gap cell as 0, queue order, queue membership, title truncation, verb pill, floor removed.
