# Changelog

All notable changes to Signal & Noise Tools are documented here.

This file holds two things only: **`## [Unreleased]`**, the working log that
accumulates across pull requests, and the **current release**. Everything older
lives in [docs/changelog/](docs/changelog/).

A pull request does not bump `Version` and does not tag — it closes an issue and
adds a bullet below. A release is a separate, deliberate act:
`tools/cut-release.sh`.

## [17.5.1] - 2026-09-21 — every write carries its own nonce

### Fixed
- **Asset and API paths are not pageviews.** The Analytics report showed a pageview at `/wp-content/uploads/sn-css/$h`: the beacon's path is client-supplied, and the excluded-path rule dropped only `/wp-admin` and `/wp-login.php`. `sn_analytics_is_excluded_path()` now also drops `/wp-content/`, `/wp-includes/`, `/wp-json/` and any path whose last segment carries a file extension, the same set the edge drops since analytics worker 1.21.4 (#33 there), so the rollup refuses the rows the edge already let through. Pinned: six dropped, two more kept (`/notes/v1.2-release/`, `/wp-content-guide/`); six pins red against the old rule. #1651.
- **Sixty-six writes shared one nonce behind the plugin dispatcher; admin-post.php with a nonce per action is the shape.** Read against 17.5.0: `inc/admin-post-handler.php` ran a single `check_admin_referer( 'sn_theme_options_nonce' )` on `admin_init` and then looked the posted `sn_action` up in `sn_admin_post_handlers()`, so a token minted for Save identity authorised Full reset, Prune unused tags, Delete webhook and the other 62; 56 classic forms across 34 files minted that nonce, as did `snt_kit_nonce()`, four kit leaves that hand-built their hidden fields and the Analytics window's export chrome; the PRG redirect and the legacy 301 were raw `header( 'Location' )` calls justified by "wp_safe_redirect() strips URL fragments", which is false against WP 7.1 (`wp_sanitize_redirect()` keeps `#`). Changed: the dispatcher registers `admin_post_sn_<action>` for every entry of the table at load (the table stays the single source of truth) and each hook runs `check_admin_referer( 'sn_' . $action )`, the capability check, the page allowlist (a `wp_die()` now, where `admin_init` returned silently), the handler and `wp_safe_redirect()` + `exit` with the same flash code and the same target; the two "strips the fragment" comments and both raw `header()` calls are gone from this file and `inc/admin-legacy-redirect.php`. Every classic form posts to `sn_admin_post_url()`, admin-post.php carrying the page, tab and sub the form was painted on, with a hidden `action=sn_<action>` and `wp_nonce_field( 'sn_<action>' )`; a form whose action rides its submit buttons (Keyring's Save and Verify all, the dashboard console's three, Insights' three, the redirect rows' Save and Delete, Webhooks' Save and Delete, Search Console's two pairs, IndexNow's two, AI settings' Run comparison beside its hidden save, the 404 log's Create and Dismiss) keeps its shape and each button prints `sn_admin_post_button()`, `name="action" value="sn_<action>"` plus a `formaction=` carrying that action's nonce through `wp_nonce_url()`, so one form holds one nonce per button and the nonce never rides the body where a second button's would override it. The one inline form, Audit log's Prune now, keeps `sn_action` and checks `sn_audit_prune_now`. The kit twin: `snt_kit_nonce( $action )` mints `wp_create_nonce( 'sn_<action>' )`, `snt_kit_form()` names the field `action` (or `sn_action` under `pipeline => inline`), `snt_kit_action_button()` posts `action`, that nonce and the admin-post pipeline for a table key or a prefixed hook alike, so `provenance_post_action()` is one call; `snt_os_host_pipeline_for()` routes any `action` field to admin-post with no declaration, admits an inline `sn_action` only on its own nonce, and the `shared` pipeline, `snt_os_host_replay_shared()` and `SNT_OS_HOST_NONCE` are deleted; `snt_os_host_replay_admin_post()` verifies a table action's nonce before firing its hook so the window's refusal names the action measured rather than core's "link expired" page. `snt_os_host_keep_forms()` and the two Analytics callers read the `action` field and keep the export form posting to admin-post.php. Pinned in `tests/openstation-host.php` (a nonce minted for `sn_save_identity` replayed against `full_reset` refuses with reason `nonce` and never calls the handler; 66 of 66 hooks registered and no `admin_init` dispatch; `sn_admin_post_url()` and `sn_admin_post_button()` byte for byte; the Location of a legacy-tab save through `wp_safe_redirect()` ending in `#sn-sec-identity`; no raw `header()` and no "strips" premise in either file; no file under `inc/` or `apps/` naming `sn_theme_options_nonce`), with the shared-pipeline group re-homed on admin-post and the inline group on its own nonce, `tests/openstation-host-dashboard.php` registering the hooks it used to sink, and the 31 leaf suites reading `action` through `snt_leaf_actions()` / `snt_leaf_names()` with the transport fields set aside; 18 red against 17.5.0 before the suite fatals on the missing helper, 7 more that cannot run there. #1614.
