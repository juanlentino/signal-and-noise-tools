# Changelog

All notable changes to Signal & Noise Tools are documented here.

This file holds two things only: **`## [Unreleased]`**, the working log that
accumulates across pull requests, and the **current release**. Everything older
lives in [docs/changelog/](docs/changelog/).

A pull request does not bump `Version` and does not tag — it closes an issue and
adds a bullet below. A release is a separate, deliberate act:
`tools/cut-release.sh`.

- **Behavior change: with the speculative loading switch off, the site now serves WordPress's own speculative loading instead of none.** Off used to switch core's feature off entirely: `sn_speculation_configuration()` answered core's `wp_speculation_rules_configuration` filter with null, so no speculation rules were printed on any page. The plugin's `/contact/*` exclusion is in those rules too. Before, it emitted nothing. Unchanged: switch on is still `prerender` with eagerness `moderate`; a logged-in visitor and a site with plain permalinks still get no speculation rules in either state (core passes null for them, and that null is returned as it is). A site with a strict `script-src` that pins inline script hashes will see a speculation rules block where the off state had none; the daily `csp_hashes` check reads the live page and reports it.
