# Changelog

All notable changes to Signal & Noise Tools are documented here.

This file holds two things only: **`## [Unreleased]`**, the working log that
accumulates across pull requests, and the **current release**. Everything older
lives in [docs/changelog/](docs/changelog/).

A pull request does not bump `Version` and does not tag — it closes an issue and
adds a bullet below. A release is a separate, deliberate act:
`tools/cut-release.sh`.

- **AI › Agent tools: one ability is one row, and first-party polls are not door traffic.** Read live 2026-09-20 (136 tools, 74,670 calls over 50 days): the telemetry records a tool's name as each door spells it (the MCP doors the projected `signal-noise__jev-tells-pass`, the lifecycle guard's direct door the slug core hands it, `signal-noise/jev-tells-pass`), and the reader grouped by that string, so one ability painted as up to three rows and the "no calls, retirement candidate" test missed a tool called through a door under the other spelling; four showed as candidates that way. Now `sn_mcp_telemetry_canonical_tool()` folds the projected name, the slug and a bare tail of every allowlisted plugin tool onto the projected name at READ time (the log is append-only evidence and is never rewritten; a theme tool or a schema-error blank stays as recorded), each row carries `calls` (every door), `door_calls` (read, rw, agent) and `direct_calls`, and the usage array carries `by_door`. The zero-call test counts door traffic only: `unused` needs zero calls on every door and a projectable tool; a tool only the plugin's own surfaces called is `first_party_only`, labelled "no caller through a door; the plugin's own surfaces called it N times. Not a retirement candidate for the code, only for the door allowlist"; `unreachable` still outranks it (direct calls prove nothing about projection) and `undetermined` is as it was. Both surfaces (the native usage block and the classic mcp-usage-block) say the same words through the classic block's three helpers: the summary counts "tools with no calls through a door", the trailing sentence states the split ("N calls: A first-party (direct), B read door, C rw, D agent", the fixture's figures pinned), and the Calls column shows door calls with the direct count in parentheses ("1 (30,000 direct)") rather than a fifth column, because neither table changes shape and the kit table needs no new key; rows sort by door calls, the polls only break ties.
